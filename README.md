## 特点

STM32C5系列是ST32系列新一代MCU，可能是将来ST主推系列（存疑😅），性能较强，功能丰富。C53系列为Cortex-M33内核，主频144Mhz，集成了单精度FPU、DSP、多个高级多种定时器，且支持12Mbps USB2.0、I³C、FDCAN等功能

选择48Pin封装的原因是它兼具具有OSC以及OSC32引脚，这对同时需要准确时间以及高速PWM是项目非常友好\
正如上面所说，我没有MCU实物调试，所以不敢用无源晶振（怕不起振），于是贴心地（真的吗）使用了两个泰晶的10ppm高精度晶振（钱包-6元），分别是25MHz和32768Hz


这块开发版使用了Type-C接口，留有CC识别下拉电阻，同时USB数据与供电均加了TVS防静电（南桥～我来保护你）

![image.png](https://)\
主供电直接从USB取电，LDO用的是立琦RT9013（别买错牌子了），标称最大输出500ma，静态电流小，动态响应不错，封装SOT23-5

![image.png](https://)\
板子预留的引脚是辅助供电，USB 5V与辅助供电都串了SS34，防倒灌\
凡是与供电相关的铜皮都加粗了（嗯，非常粗），电容也是管饱\
PS：MLCC电容非常脆，稍有磕碰就容易短路，要着重保护反面那几个电容

![3D\_PCB1\_2026-08-30侧 Magenta.png](https://)\
（这个能叫最小系统板吗）\
除了复位，还从PC13引出了一个按键，由于PC13还可复用为WAUP4，就叫它唤醒键吧。\
如果不需要低功耗场景，可以设置为普通按键

另外从功能比较少的PE2引出了LED，0805封装，亮度根据电阻调符合自己口味的\
当然，由于用了一个MDD 8050控制，如果不想要LED，还可以从LED焊盘飞一根线，限流电阻那里一坨锡，苦一苦LDO，带载能力还是有一些的
